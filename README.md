# Развес линейных массивов

Калькулятор развеса линейных массивов и сабвуферов: HK Audio CAD 208 и CAD 115 Sub, L-Acoustics Kara II, SB18, KS28, SB28.

**Открыть:** https://pichugindd.github.io/razves/

## Что умеет

- Несколько подвесов с точными координатами X, Y, Z и поворотом, зеркальная копия L/R
- Вид сверху с картой уровня и перетаскиванием подвесов, разрез по оси любого подвеса
- Прямоугольные зоны публики со своими размерами: партер, балкон с подъёмом к задним рядам
- Углы между колонками — только допустимые для модели (CAD 208: 0–15° шаг 1,5°; Kara II: 0–10°)
- Кнопка «Подобрать углы»: ровный уровень по публике, верхняя колонка — на последний ряд
- Уровень по залу с учётом фазы: физика линейного массива, интерференция сабов, кардиоидные пачки, задержка и полярность
- Пачки сабвуферов: лёжа или стоя на боку, сколько корпусов, сколько развёрнуто назад
- Карта уровня по розовому шуму или по отдельной частоте от 40 Гц до 8 кГц
- Покрытие ближнего и дальнего ряда, вес подвеса

## Ограничения

Диаграммы колонок — модель по паспорту и геометрии, а не замеры производителя: форма распределения уровня близка к реальной, точные децибелы — нет. Отражения и фаза фильтров кроссовера не учитываются. Финальную настройку делай по замеру, безопасность подвеса проверяй по документации производителя.

Неофициальный калькулятор, с HK Audio и L-Acoustics не связан. Данные колонок — из открытых материалов производителей.
