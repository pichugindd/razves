# Развес линейных массивов

Калькулятор развеса линейных массивов: HK Audio CAD 208 и L-Acoustics Kara II.

**Открыть:** https://pichguindd.github.io/razves/

## Что умеет

- Несколько подвесов с точными координатами X, Y, Z и поворотом, зеркальная копия L/R
- Вид сверху с картой уровня и перетаскиванием подвесов, разрез по оси любого подвеса
- Зоны публики любой формы по глубине и ширине: партер, балкон с подъёмом
- Углы между колонками — только допустимые для модели (CAD 208: 0–15° шаг 1,5°; Kara II: 0–10°)
- Кнопка «Подобрать углы»: ровный уровень по публике, верхняя колонка — на последний ряд
- Покрытие первого и последнего ряда, примерный уровень по глубине зала, вес подвеса

## Ограничения

Расчёт геометрический, уровень звука — оценка без интерференции. Финальную настройку делай по замеру, безопасность подвеса проверяй по мануалу HK Audio.

Неофициальный калькулятор, с HK Audio и L-Acoustics не связан. Данные колонок — из открытых материалов производителей.
