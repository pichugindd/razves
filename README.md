# Развес CAD 208

Калькулятор подвеса линейного массива HK Audio CADIS CAD 208.

**Открыть:** https://pichguindd.github.io/razves/

## Что умеет

- Разрез зала сбоку: массив, лучи из центра каждой колонки, конусы покрытия
- Углы между колонками — только допустимые для CAD 208 (0–15° с шагом 1,5°, к раме до 7,5°)
- Кнопка «Подобрать углы»: ровный уровень по публике, верхняя колонка — на последний ряд
- Покрытие первого и последнего ряда, примерный уровень по глубине зала, вес подвеса

## Ограничения

Расчёт геометрический, уровень звука — оценка без интерференции. Финальную настройку делай по замеру, безопасность подвеса проверяй по мануалу HK Audio.

Неофициальный калькулятор, с HK Audio не связан. Размеры колонки — по открытому чертежу HK Audio, углы и нагрузки — из CADIS Manual 1.0.
